## 👋 About me

I'm a **Tech Lead at [NotChatbot](https://www.notchatbot.com/)**, an AI-powered conversational platform. I design software architecture and build AI systems that run in production: **RAG, agents and MCP**, on top of real-time backends. Based in Córdoba, Argentina 🇦🇷.

## 🧠 What I work on

- 🤖 **AI engineering:** RAG, agents and tool calling.
- 🏗️ **Software architecture:** scalable, real-time systems.
- 🧭 **Technical leadership:** code quality, production stability and AI-assisted workflows.
- 💸 **Efficiency:** making AI faster and cheaper to run.
