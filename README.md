## About me

I'm a **Tech Lead at [NotChatbot](https://www.notchatbot.com/)**, where I lead a team of 5 developers building an AI-powered conversational platform on WhatsApp, Instagram and Meta APIs. I have 4+ years of experience shipping production software, and I care about scalable architecture, code quality and production stability.

I just graduated as **Licenciado en Informática** (Computer Science, Universidad Siglo 21) 🎓. My final thesis, a **knowledge management system built on Retrieval-Augmented Generation (RAG)**, was graded **10/10**.

## What I work on

- 🤖 **AI engineering:** RAG pipelines, AI agents and MCP servers, tool calling, vector search and conversational memory.
- 💸 **AI cost optimization:** cut AI costs by roughly 50% by improving memory handling, tool calls and database queries.
- ⚡ **Real-time platforms:** multichannel messaging with Convex, WebSockets and the WhatsApp/Meta APIs.
- 🧭 **Technical leadership:** planning, code reviews, internal training, and AI-driven workflows for the team (skills, agents, ticket autodev).
- 🏗️ **Infrastructure:** Vercel, self-hosted AI inference on RunPod, analytics with MotherDuck, Docker on Linux VPS.
